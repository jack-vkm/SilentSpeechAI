# SilentVoice AI (Expo + TypeScript)

Mobile app scaffold for lip-reading silent speech recognition using external AI APIs.

Run:

1. Copy `.env.example` → `.env` and set `AI_API_KEY`.
	- For Grok integration, set `XAI_API_KEY` in `.env` as well.
2. Install dependencies: `npm install` or `yarn`.
3. Start: `npm start` or `expo start`.

See `src/` for screens, components, and services.
